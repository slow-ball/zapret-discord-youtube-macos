# Изменения

## 1.0.0

Первый релиз.

- Установка zapret (bol-van v72.13) одной командой, с проверкой контрольной суммы
- Один файл `zapret.command`: первый запуск — установка, дальше — меню управления
- 15 стратегий tpws
- Параллельный автоподбор стратегии без остановки zapret
- Автопочинка: фоновая проверка YouTube и переключение стратегии
- Диагностика
- Иконка в строке меню (SwiftBar)
- Свои списки и исключения, которые не перезаписываются при обновлении
- Блокировка QUIC, поддержка IPv6, уведомления macOS
