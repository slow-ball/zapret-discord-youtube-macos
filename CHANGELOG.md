# Изменения

## 3.1.0

- **Подписанные обновления.** Каждый релиз подписан ключом, которого нет ни на GitHub, ни в репозитории.
  Обновление и автообновление проверяют подпись встроенным в macOS `ssh-keygen` и без неё ничего
  не ставят: даже доступ к аккаунту GitHub не позволит подсунуть код на маки с zapret.
  Ключей два: основной и запасной, который хранится не на компьютере
- **Обновление без пароля.** Раз обновление ставит только подписанный релиз, пароль больше не нужен:
  «Обновить» — одно нажатие. Вернуть без пароля можно только предыдущую версию
- **Проверка подлинности.** Приложение само скачивает подписанный релиз установленной версии, сверяет
  подпись и каждый файл в `/opt/zapret-macos`. Если что-то изменено — уведомление и кнопка
  «Переустановить» в «Проверке»
- **Смена стратегии без обрыва.** Движок перечитывает стратегию на ходу: сеть, туннель и правила
  файрвола остаются, интернет пропадает на доли секунды вместо пары секунд
- **Автоподбор за секунды.** Сначала текущая стратегия и те, что работали в прошлый раз, и подбор
  останавливается на первой хорошей: всё открывается, работает голос Discord, YouTube быстрее 1 МБ/с.
  «Проверить все 37» — полный перебор с выбором самой быстрой
- Полный перебор тоже быстрее: стратегии сменяются без перезапуска движка, а замер «без zapret»
  идёт параллельно и занимает секунды вместо полуминуты
- **По-английски.** Приложение, сообщения zapret и меню в Терминале говорят на языке macOS:
  русский или английский. Описание проекта — и в [README.en.md](README.en.md)

Вернуться из 3.1 можно только к подписанным версиям, то есть к 3.1 и новее.

## 3.0.0

Один движок и свои стратегии. zapret от bol-van больше не нужен: всё работает на nfqws,
собранном в этом проекте.

- **Свои стратегии macOS** вместо tpws: 15 штук — бывшие стратегии tpws на nfqws и новые с фейками.
  Теперь у всех стратегий есть QUIC, голос Discord и игры
- **Свой глубокий подбор**: сотни вариантов nfqws для одного сайта. Найденный работает только
  для этого сайта, основная стратегия не меняется
- **Стратегии для сайтов** — с любой стратегией, не только с tpws
- Автоподбор быстрее: стратегии проверяются без самопроверки IPv6
- **Обновления только из релизов**: приложение и автообновление ставят опубликованную версию,
  а не каждое изменение на GitHub. Кнопка «Проверить» в Настройках и в меню zapret
- **«Что нового»** после обновления и **«Вернуть версию»**, если после обновления стало хуже
- **Журнал**: что делал zapret, его движок и прокси для Telegram, с поиском. Логи больше не разрастаются
- **После обновления macOS** zapret сам проверяет и восстанавливает правило sudo, службы и правила
  файрвола — при запуске приложения и в фоновой проверке
- e2e проверяет каждое изменение на macOS 14, 15 и 26, на Apple Silicon и Intel, и переезд с 2.x

Переезд с 2.x автоматический: служба tpws останавливается, `/opt/zapret` удаляется, если его
поставил zapret-macos (свой zapret с изменённым конфигом остаётся, его служба выключается).
Стратегии tpws заменяются на nfqws general, найденные с ними стратегии для сайтов подберутся заново.

## 2.2.1

Исправления безопасности — обновиться стоит всем.

- Действия от root больше не доверяют папке проекта: свои списки читаются и дописываются с правами владельца папки. Раньше подменённый ссылкой список позволял прочитать или дописать системный файл без пароля
- Автообновление от root запускает новый скрипт из своей загрузки, а не из папки проекта, которую может изменить любая программа пользователя
- Адрес сайта проверяется целиком: строка с переводом строки могла попасть в имя стратегии и дальше в конфиг, который zapret исполняет от root
- zapret.sh разделён на модули (src/lib), добавлены быстрые модульные тесты; e2e проверяет защиту от подмены файлов и обновление от root

## 2.0.0

- Второй движок nfqws (порт Flowseal, utunws): 22 стратегии из Windows-версии 1.10.4 с фейковыми пакетами, обход QUIC, голос Discord по UDP
- Стратегии nfqws переносятся из Windows-версии скриптом `build/import-windows.py`: новая ALT13, обновлённые фейки, списки DNS-over-HTTPS и Cloudflare
- nfqws сокращает таймаут установки TCP-соединения до 7 секунд, чтобы видео быстрее восстанавливалось после обрыва
- Умный режим: сайты, которые не открываются без обхода, находятся и обрабатываются сами, остальные не трогаются
- Своя стратегия tpws для каждого сайта, который не открывает основная (`learn`, в фоне — вместе с автопочинкой)
- nfqws обрабатывает IPv6, если проверка при запуске прошла
- Сборка nfqws из исходников: `build/utunws.sh` и workflow «utunws»
- Приложение для macOS (SwiftUI): иконка в строке меню и окно со стратегиями, сайтами, играми, Telegram, диагностикой и настройками
- Прокси для Telegram Desktop (tg-ws-proxy от Flowseal): `telegram`, пункт меню 15, подключение одной кнопкой, сквозная проверка `telegram test`, свободный порт, если 1443 занят
- Виджет, уведомления с кнопками, горячая клавиша ⌃⌥Z, ссылки `zapret://`
- Приложение открывает окно при запуске вручную; прокси для Telegram подключается из строки меню одной кнопкой
- Установка без Терминала: zapret.dmg, экран приветствия и кнопка «Установить» в приложении
- Приложение обновляется вместе с проектом; после обновления копия скрипта для служб обновляется, даже если zapret не запущен
- «Сайт не открывается?»: `site <адрес>` — в свой список, своя стратегия, проверка как в браузере; редактор своих списков в приложении
- Диагностика с кнопками «Исправить»; `dns` ставит DNS 1.1.1.1 для активного подключения

- Новая иконка: три волны в градиенте
- Стратегии Windows-версии (nfqws) — первыми в списках и в приоритете при автоподборе; при установке включается nfqws general
- Игровой фильтр, как Game Filter в Windows-версии (`game`, пункт меню 13)
